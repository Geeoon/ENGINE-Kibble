Installation and Setup
======================

Prerequisites
-------------

- Python 3.x
- MongoDB
- pip

Clone the Repository
--------------------

.. code-block:: bash

   git clone https://github.com/Geeoon/ENGINE-Kibble.git
   cd ENGINE-Kibble

Install Dependencies
--------------------

.. code-block:: bash

   pip install -r requirements.txt

Database Setup
--------------

Ensure MongoDB is running and the required collections are available.

Run the System
--------------

.. code-block:: bash

   python main.py
