Installation and Setup¶

Prerequisites¶

  • Python 3.x

  • MongoDB

  • pip

Clone the Repository¶

git clone https://github.com/Geeoon/ENGINE-Kibble.git
cd ENGINE-Kibble

Install Dependencies¶

pip install -r requirements.txt

Database Setup¶

Ensure MongoDB is running and the required collections are available.

Run the System¶

python main.py
